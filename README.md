# odin-etch-a-sketch

This project is the fourth self-reliant exercise provided by The Odin Project open source curriculum.

## Expectations before starting the exercise

The assignment for this exercise is to build an interactive grid to "draw" on by changing the colour of its tiles when hovering over them with the mouse. I am looking forward to this exercise, because it combines JavaScript functionality and CSS styling in a creative and fun way. I expect to implement DOM manipulation that goes beyond basic click events and utilises event objects to handle user interactions in a meaningful way. Looking further ahead, I also see potential for expanding the project after the exercise is completed. Adding a variety of interactions to the tiles could serve as a little playground to broaden my knowledge of JavaScript and CSS and consolidate what I have already learned.
